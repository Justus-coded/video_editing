# Video Editing Skills

Reusable AI-assisted skills for planning and producing polished video edits.

These skills are written in Markdown and can be adapted for Cursor, Claude Code, Codex, Gemini CLI, GitHub Copilot, or other coding assistants that support instruction files or reusable workflows.

## Included skills

- **Higgsfield AI Video Editing** — plans precise cuts, generates supporting visuals, adds captions, motion graphics, transitions, audio cleanup, and branded outros while preserving source quality.

## Repository structure

```text
video_editing/
└── higgsfield-video-editing/
    └── SKILL.md
```

## Usage

Copy or reference the relevant skill in your coding tool's instructions, skills, or agent-configuration directory. Follow that tool's documentation for the appropriate installation location.

Then ask the assistant to use the skill and provide your video, editing instructions, brand assets, and desired output format.

## Customization

Each skill is designed to be modified. Update its prompts, brand defaults, editing workflow, and export settings for your own production process.

## Contributions

New video-editing skills and improvements are welcome. Keep skills reusable, tool-agnostic, and free of private paths or account-specific information.
